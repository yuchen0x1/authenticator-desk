# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/yuchen0x1/authenticator-desk/security/advisories/new). Include the affected version, OS, build type, and steps using synthetic credentials. Keep vault databases, backup files, passwords, QR codes, OTP seeds and production tokens out of reports.

Security updates target the latest stable Windows release. The [security model](docs/security-model.md) describes the vault and local trust boundaries. Release hashes are published with each new release and can be compared with the downloaded files before manual installation.
