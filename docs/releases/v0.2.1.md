## Release overview

AUTHENTICATOR DESK 0.2.1 is a maintenance patch for test discovery and release-context validation. It adds no new application features.

## Fixes

- Limit Vitest discovery to `src/**/*.{test,spec}.{ts,tsx}` so the frontend runner does not collect Node.js test scripts.
- Run `scripts/release-context.test.mjs` independently with `node --test` in CI, retaining the release trust checks.
- Implement the tested `isTrustedReleaseInvocation` allowlist for this repository's version-tag pushes and matching release workflow reference; reject other invocation contexts.

## Downloads and upgrading

When v0.2.1 is published, choose the Windows x64 installer matching your existing installation: EXE (NSIS) or MSI. Verify a manual download against SHA256SUMS.txt, create an encrypted backup and close the application before installing. See the [update and recovery guide](https://github.com/yuchen0x1/authenticator-desk/blob/main/docs/updating.md) for installation and rollback instructions.

This patch does not change the vault schema, installer behavior or updater security boundaries. The existing signing, installer verification and recovery requirements still apply. This preparation does not claim new installer or live-update acceptance results.
