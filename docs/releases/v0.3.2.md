# AUTHENTICATOR DESK v0.3.2

## 本版范围 / Release scope

这是基于 v0.3.1 的多语言与维护补丁。是否已经公开、实际 tag 提交、安装包和验证结果，以 [GitHub Release](https://github.com/yuchen0x1/authenticator-desk/releases/tag/v0.3.2) 及对应的 [Release 工作流](https://github.com/yuchen0x1/authenticator-desk/actions/workflows/release.yml) 为准；本文件本身不是发布成功或验收完成的证明。

### 修复与改进

- 主窗口和收藏快捷面板在保险库尚未解锁的冷启动阶段记住已保存的界面语言；解锁后的认证设置仍然是权威来源。
- 语言提示仅包含 `zh-CN`、`zh-TW`、`en` 或 `ja`，不包含密码、账户、OTP 密钥或保险库内容。未知值或存储不可用时安全回退。
- 保存失败、过期请求和旧保险库会话的延迟回调不会覆盖新会话的语言设置。
- 补齐收藏状态变更审计事件，以及导入、备份、二维码图片原生文件筛选标签的四语翻译。
- 提供简体中文、繁体中文、English、日本語完整 README，保留十张已有真实界面截图与真实的安全、平台和验收边界。
- 更新 `rfd` 至 0.18.0、`windows-version` 至 0.100.0，并更新已验证的 GitHub Actions 依赖；后续兼容依赖更新按组提交，不禁用安全更新。
- 为密码轮换回归断言补充安全的错误类型诊断，不输出凭据或保险库内容，不放宽断言，也不修改生产文件锁语义。

### English summary

- Remember the saved interface language on locked cold starts in both the main window and favorites panel, while keeping authenticated vault settings authoritative after unlock.
- Reject unsupported locale hints and prevent failed or stale saves from overwriting a newer session's language.
- Complete four-language favorite-audit messages and native import, backup and QR-image filter labels.
- Publish complete Simplified Chinese, Traditional Chinese, English and Japanese README editions with honest security and verification limits.
- Update the native file-dialog and Windows-version dependencies and the validated GitHub Actions dependencies.
- Improve password-rotation test diagnostics without relaxing authentication checks or changing production lease behavior.

## 兼容性与升级 / Compatibility and upgrading

SQLite schema 1、保险库加密、`.authdesk` 备份格式、应用标识和存储路径不变。本补丁不引入数据迁移，不要求重新创建保险库。升级前先备份，完全退出旧版及托盘进程，并保持相同安装包类型（NSIS EXE 或 MSI）。不要删除活动保险库的 `.lock` 文件。

The vault schema, encryption and backup formats, application identifier and storage paths are unchanged. Back up first, fully exit all clients, and keep the same installer family. Existing historical upgrade evidence does not prove that automatic updater installation, rollback or every old-version MSI upgrade has been qualified for this release. See [update and recovery](../updating.md).

## 发布门禁 / Publication gates

正式 tag 必须指向已在 `main` 中的准确提交，且 package、Cargo、Tauri 和 Cargo.lock 应用版本一致。现有发布流程要求 Security、前端与 Rust 测试、Windows 打包、分别运行的 NSIS/MSI 安装生命周期检查、真实 updater 签名验证全部通过，再创建草稿、下载验证、公开发布、重新下载验证，并核对稳定 `update.json`。任何一步失败都不等于发布完成。

预期资产为：

- `AuthenticatorDesk-0.3.2-windows-x64-setup.exe` 及其 `.sig`
- `AuthenticatorDesk-0.3.2-windows-x64.msi` 及其 `.sig`
- `release-assets.json`
- `SHA256SUMS.txt`
- `update.json`

Updater/Minisign signatures authenticate update payloads; they are **not Windows Authenticode publisher signatures**. This release does not provision a Windows publisher certificate. Local unsigned builds are not substitutes for the signed release assets.

## 仍然存在的限制 / Remaining limitations

- **`glib 0.18.5` 的 `RUSTSEC-2024-0429` / `GHSA-wrw7-89jp-8q8g` 告警未修复。** 它来自当前 Tauri Linux GTK 间接依赖链，不在 Windows x64 目标依赖图中；兼容升级仍受上游约束。没有忽略或关闭告警。详见 [open dependency security advisory](../known-limitations.md#open-dependency-security-advisory)。
- 提交 `c7134b5` 的 macOS 核心 CI 曾有一次密码轮换断言失败，原断言未记录实际返回错误。增加诊断后的 `3c1221b` CI 通过，但根因仍未确认；不能将“未复现”描述为修复了生产认证或文件锁漏洞。
- Windows 11 x64 / WebView2 是桌面验收目标。Linux/macOS CI 只验证 portable Rust core，不代表原生桌面分发支持。
- Windows Hello、摄像头捕获、加密第三方导入解密、云同步和密码恢复不在本版新增能力中。
- 真实旧版自动更新与回退、Windows ACL、剪贴板历史/云副本、完整原生交互及非 NTFS 文件系统仍需各自证据；不能把自动测试、旧截图或历史手动升级记录当作全部验收完成。
