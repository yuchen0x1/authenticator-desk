## Release overview

AUTHENTICATOR DESK 0.2.0 introduces signed application updates for Windows x64. Open Settings → Application updates to check for a stable release, view its notes and size, and choose when to install. Version 0.1.0 users install this release manually.

## Downloads

Choose the same installer type that you use today. EXE is the standard per-user NSIS installer. MSI is available for MSI-managed installations. Compare the file with SHA256SUMS.txt before a manual installation.

The existing vault, settings, imports, backups and shortcuts are compatible with this version. Create an encrypted backup before changing versions. Restart the application after manual installation.

## Security and compatibility

The update channel verifies a signed manifest, the installer signature, the signed product version and SHA-256. Windows Authenticode is separate from updater signing. Windows 11 x64 is the desktop acceptance target. See the repository's update guide for recovery steps.
