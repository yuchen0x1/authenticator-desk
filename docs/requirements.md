# AUTHENTICATOR DESK — 完整项目开发任务书

你现在是一名资深 Windows 桌面应用开发工程师、Rust 安全工程师、密码学工程师、UI/UX 设计师和软件测试工程师。

你的任务是从零开始（如果当前仓库已有项目，则在充分检查现有项目后继续开发），构建一款完整的 Windows 桌面多平台 2FA 身份验证器管理软件。

项目名称：AUTHENTICATOR DESK

项目定位：

一款以本地安全为核心，支持多平台账户管理、实时验证码生成、批量迁移、加密保险库、自动备份、安全审计的专业桌面版 2FA 管理工具。

注意：这不是演示项目，不是静态页面，不是只有界面的原型，而是真正可以使用的桌面软件。

==================================================
第三部分：核心验证码引擎
==================================================

必须完整实现：

一、TOTP

按照 RFC 6238 实现。

支持：

- HMAC-SHA1
- HMAC-SHA256
- HMAC-SHA512
- 6 位验证码
- 7 位验证码
- 8 位验证码
- 默认 30 秒周期
- 可配置时间周期
- 自定义 T0
- 正确处理时间戳和大整数。

二、HOTP

按照 RFC 4226 实现。

支持：

- 计数器管理
- 手动递增
- 计数器持久化
- 验证码重新生成
- 防止计数器异常回退。

三、实时刷新

必须实现：

- 全局统一时间基准。
- 每秒更新倒计时。
- 到期时自动刷新验证码。
- 不允许每张账户卡片各自维护不一致的计时器。
- 窗口切换和系统休眠后正确恢复。
- 检测系统时间发生明显变化。
- 避免使用前端本地时间计算产生长期漂移。
- 时间校准功能。
- 显示当前时间偏差和校准状态。

四、验证码展示

每个账户展示：

- 平台图标
- 平台名称
- 账户名称
- 六位或八位验证码
- 倒计时
- 环形进度条
- 复制按钮
- 收藏状态
- 所属分类。

复制验证码时：

- 复制完整验证码。
- 显示复制成功提示。
- 可设置自动清理剪贴板。
- 清理前检查剪贴板内容是否仍为本应用写入的验证码，避免删除用户后来复制的其他内容。
- 不记录验证码到日志。

==================================================
第六部分：加密保险库
==================================================

这是项目最高优先级模块之一。

必须实现：

1. 首次启动设置主密码。
2. 主密码验证。
3. Argon2id 密钥派生。
4. AES-256-GCM 数据加密。
5. 每次加密使用安全随机数。
6. 密钥与普通账户信息分离。
7. 防止明文密钥落盘。
8. 防止日志泄露密钥。
9. 自动锁定。
10. 手动锁定。
11. 闲置锁定时间配置。
12. Windows Hello 快捷解锁（支持条件下）。
13. 隐藏全部验证码。
14. 安全删除账户。
15. 锁定后清理内存中的敏感数据，尽可能缩短明文驻留时间。
16. 数据库完整性校验。
17. 加密备份。
18. 备份恢复。

安全设计：

- 默认离线运行。
- 不强制注册账号。
- 不强制联网。
- 不上传密钥。
- 不将主密码保存在普通配置文件中。
- 不使用硬编码加密密钥。
- 不使用可逆的普通 Base64 代替加密。
- 不允许通过调试日志输出 Secret。
- 不允许把 Secret 放进前端持久化存储。
- 网络时间校准只传输时间请求，不传输账户数据。
- 对加密操作进行完整性校验。

主密码忘记后不得宣称可以无损找回原始密钥。必须明确备份恢复和密码丢失的边界。
